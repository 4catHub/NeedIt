# Tax 사용자 흐름

1. 홈에서 7개 서비스 중 활성화된 종합소득세 환급을 선택합니다.
2. `/tax`에서 대상 설명, 원천징수와 환급의 차이, 직접 처리 방식과 유의사항을 읽습니다. API 없이도 공식 가이드를 볼 수 있습니다.
3. `/tax/check`에서 귀속연도 → 소득 유형 → 금액 → 확인 순서로 진행합니다.
4. 필수 항목 누락과 잘못된 금액은 다음 단계로 넘어가기 전에 표시합니다. 금액은 원 단위 정수이고 0도 유효합니다. 원천징수세액은 모름을 선택할 수 있습니다. 수입을 근거로 원천징수나 환급액을 추정하지 않습니다.
5. 이전 단계로 돌아가도 값이 유지됩니다. 확인 화면에서는 연도·소득 유형·금액만 표시합니다. 버튼 로딩과 중복 제출 차단, 요청 취소, 오류 후 재시도를 제공합니다.
6. 실제 모드는 eligibility → 지원 여부 확인 → estimate → guide를 호출합니다. Mock은 전송 없이 체험 안내만 반환합니다.
7. `/tax/result`에서 신고 관련 상태와 확인 항목을 봅니다. 상태는 확인 필요, 추가 정보 필요, 미지원으로 구분합니다. 계산 가능한 API 응답에는 예상액을 표시하고 확정 금액이 아님을 안내합니다. 0원과 금액 없음은 구분합니다.
8. 직접 처리와 민간 서비스를 비교합니다. 업체별 시간·가격은 추정하지 않습니다. 선택적으로 입력한 수수료에 한해서 차액을 계산하며, 사용자 입력 기반임을 표시합니다.
9. 직접 처리 방법 버튼으로 가이드로 이동하거나 다른 서비스 목록을 살펴볼 수 있습니다. 가이드에는 준비물·로그인·신고 메뉴·자료 검토·제출 후 확인사항·공식 출처·확인 날짜가 포함됩니다.
10. 홈택스는 새 창에서 열리며 NeedIt?이 신고를 대행하지 않습니다. 법령과 UI 변경 가능성을 안내합니다.

`입력 수정하기`는 기존 값을 유지합니다. `입력값과 결과 지우기`는 메모리의 값을 지웁니다. 새로고침·새 창·직접 결과 URL 접속 시에는 입력부터 시작하는 안내와 정적 공식 가이드를 보여줍니다.
