# API 연결

## 현재 상태와 계약의 출처

2026-10-15 현재 작업공간과 인접 `4d4cat-services` 저장소를 조사했습니다. Needit controller/DTO/OpenAPI 파일을 발견하지 못했고, 제공된 API 서버 URL도 없습니다. 따라서 실제 API 호환성을 주장하지 않습니다.

`contracts/tax-preview.openapi.json`은 **프론트 체험을 위한 임시 명세**입니다. 플랜의 예상 endpoint를 사용하되 백엔드 계약으로 간주하지 않습니다. 생성 타입도 `tax-preview.generated.ts`로 명명했습니다. 실제 백엔드 DTO를 임의로 정의했다는 의미가 아닙니다.

```powershell
npm run api:generate
npm run api:check
```

임시 명세 → 자동 타입 → 어댑터 인터페이스 순서입니다. Zod 응답 검증은 잘못된 상태·금액·날짜 형식을 차단합니다. `AVAILABLE`에는 0 이상의 정수 금액이 있어야 하며 다른 상태에는 금액이 없어야 합니다.

## Mock과 live

`NEXT_PUBLIC_NEEDIT_API_MODE=mock`이 기본입니다. Mock은 네트워크 전송 없이 `MORE_INFO`와 계산 불가를 반환합니다. 임의 환급금이나 세법 규칙이 없습니다. 입력·결과 화면에 체험 모드와 실제 판단을 하지 않았다는 안내를 표시합니다.

`live`는 별도 `createLiveAdapter`로 분리됩니다. 미검증 계약이나 잘못된 base URL이면 요청 전 사용자 친화적인 준비 중 오류를 표시합니다. `NEXT_PUBLIC_NEEDIT_CONTRACT_VERIFIED=true`는 계약을 실제로 교체하고 검증한 배포에서만 설정합니다. 이 플래그 자체가 계약 검증을 대신하지는 않습니다.

현재 준비된 **예상** 경로:

| 메서드 | 경로                             | 임시 기능             |
| ------ | -------------------------------- | --------------------- |
| POST   | `/api/needit/v1/tax/eligibility` | 신고 관련 상태        |
| POST   | `/api/needit/v1/tax/estimate`    | 예상액 또는 계산 불가 |
| GET    | `/api/needit/v1/tax/guide`       | 공식 가이드           |

입력은 귀속연도·소득 유형·총수입·원천징수세액(null=모름)뿐입니다. 실제 지원 연도/소득 유형/추가 조건은 아직 확인되지 않았습니다. 추가 조건이나 개인정보를 선제적으로 수집하지 않습니다.

## 실제 계약을 받았을 때

1. 신뢰할 수 있는 백엔드 OpenAPI를 받습니다. 해당 버전과 서버 URL을 기록합니다.
2. 임시 명세를 실제 계약 파일로 교체하고 `api:generate`와 `api:check`의 입력·생성 파일명을 변경합니다.
3. 실제 생성 DTO를 사용하도록 `api/types.ts`를 바꾸고 어댑터 요청·응답 매핑과 런타임 검증을 갱신합니다. 백엔드에 응답 wrapper가 있으면 여기서 처리합니다.
4. 실제 지원 연도·소득 유형·추가 필드만 폼에 반영하고 임시 연도 안내를 교체합니다. 백엔드에서 확인되지 않은 필드는 보내지 않습니다.
5. 실제 상태값과 계산 불가 사유·공식 출처를 결과 화면에 매핑합니다. 직접 입력한 원천징수액을 환급액으로 바꾸지 않습니다.
6. 인증이 필요한지, 공개 API인지 확인하고 CORS·HTTPS·OPTIONS를 검증합니다. 현재 credential은 `omit`입니다. 비밀정보를 공개 환경 변수에 넣지 않습니다.
7. 실제 서버 대상으로 정상·계산 불가·미지원·400/422·5xx·네트워크 실패를 확인하고 계약 테스트 fixture를 교체합니다.
8. `NEXT_PUBLIC_NEEDIT_API_MODE=live`, base URL, verified flag를 빌드 전에 지정하고 다시 빌드합니다.

## 실패 처리

각 요청은 12초 타임아웃입니다. 필수 eligibility 실패는 확인 화면에 오류를 표시하고 재시도할 수 있게 입력을 유지합니다. 미지원 상태에서는 estimate를 호출하지 않습니다. estimate/guide만 실패하면 성공한 진단을 보존하고 계산 불가 또는 공식 출처가 있는 정적 가이드를 표시합니다.

400/422, 서버 오류, 네트워크, 타임아웃, 응답 계약 오류를 공통 메시지로 변환합니다. 서버 오류 본문·Tax 입력을 콘솔·분석 이벤트·URL로 내보내지 않습니다. 공식 링크는 HTTPS 국세청/홈택스 도메인만 렌더링합니다. 실제 API의 가이드에 출처와 확인일이 있으면 그대로 표시합니다.

테스트의 금액 있는 응답은 브라우저에서 주입하는 fixture입니다. Mock 런타임은 금액을 반환하지 않습니다. E2E의 `live-adapter` 이름은 HTTP 어댑터 검증을 뜻하며 실제 백엔드 연동 성공을 뜻하지 않습니다.
